## Dokumentasi Skripsi Final (Final Thesis Phase)

Direktori ini berisi seluruh naskah dan dokumen untuk **fase skripsi final** (Semester 7/Tugas Akhir):

- `thesis/`: Naskah skripsi lengkap (5 Bab: Bab 1 Pendahuluan, Bab 2 Tinjauan Pustaka, Bab 3 Metodologi, Bab 4 Hasil & Pembahasan, Bab 5 Kesimpulan & Saran).
- `presentation/`: Slide beamer untuk sidang ujian skripsi.

### Perintah Build Skripsi

```bash
# Build naskah skripsi PDF
make thesis

# Build slide presentasi sidang skripsi PDF
make thesis-slides
```
