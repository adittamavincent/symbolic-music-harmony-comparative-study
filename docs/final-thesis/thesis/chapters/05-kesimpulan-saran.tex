\section{Kesimpulan dan Saran}

\subsection{Kesimpulan}

Berdasarkan hasil analisis komparatif dan pengujian evaluasi kaidah harmoni fungsional Gustav Strube terhadap tiga generasi model AI musik simbolik (DeepBach, Coconet, dan NotaGen), ditarik kesimpulan sebagai berikut:

\begin{enumerate}
    \item Tingkat kepatuhan terhadap kaidah harmoni formal berbeda secara signifikan antar arsitektur generatif musik.
    \item Peningkatan tingkat batasan (\textit{conditioning level}) memberikan dampak yang terukur dalam mengurangi tingkat pelanggaran gerak paralel.
    \item Framework evaluasi berbasis kaidah musikologis Strube terbukti efektif sebagai instrumen audit biner yang objektif dan dapat direplikasi.
\end{enumerate}

\subsection{Saran}

Untuk penelitian dan pengembangan selanjutnya, disarankan:
\begin{enumerate}
    \item Mengembangkan deteksi resolusi nada penuntun (\textit{leading tone resolution}) ke seluruh suara (Alto, Tenor, Bass) secara kontekstual.
    \item Mengintegrasikan modul evaluasi kaidah harmoni ini sebagai fungsi penalti langsung (\textit{reinforcement learning / loss constraint}) saat pelatihan model musik baru.
    \item Memperluas kerangka evaluasi untuk genre polifoni non-klasik dan kontrapung bebas.
\end{enumerate}
